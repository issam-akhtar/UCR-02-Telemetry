About This Project
------------------
Welcome to the comprehensive documentation for the UCR-02-Telemetry system, developed by the University of Calgary Racing Team for their Formula SAE Electric racecar.

.. centered:: Visit the Telemetry Website here: `UCR-02-Telemetry <http://184.64.123.31:50003/dashboard>`_

This documentation provides detailed information on the architecture, implementation, and usage of the telemetry system. It's designed to serve as a complete reference for developers working with the system.

The UCR-02-Telemetry system was developed from scratch as a capstone project by:

.. centered:: **Issam Akhtar**, **Hamza Niaz**, **Awab Khurram**, **Gibran Akmal**, **Bill Thai**, **Mohammad Elnaggar**

.. centered:: *University of Calgary, Schulich School of Engineering*

.. note::
   This project won the **Silver Medal** at the Engineering Design Fair.

Documentation was authored by **Issam Akhtar** using Sphinx.
